Политика конфиденциальности

Приложение «Я ХУдЕЮ»

Последнее обновление: 2 октября 2026 г.

1. Общая информация

«Я ХУдЕЮ» — приложение для ведения данных о питании, весе, физической активности, тренировках и прогрессе пользователя.

2. Данные пользователя

Приложение может обрабатывать данные, которые пользователь самостоятельно вводит в приложение, а также данные, к которым пользователь явно предоставляет доступ.

3. Google-аккаунт и Google Drive

При подключении Google-аккаунта приложение может использовать Google Drive для хранения и синхронизации данных приложения. Доступ осуществляется только после разрешения пользователя.

Приложение использует область данных Google Drive, предназначенную для данных самого приложения. Доступ к этим данным используется для функций резервного копирования и синхронизации.

4. Передача данных

Данные приложения не продаются третьим лицам. Данные могут передаваться сервисам, необходимым для работы выбранных пользователем функций, например сервисам Google при использовании Google-аккаунта и облачной синхронизации.

5. Управление данными

Пользователь может прекратить использование облачной синхронизации и отключить Google-аккаунт в приложении.

6. Изменения политики

Политика конфиденциальности может обновляться при изменении функций приложения или способов обработки данных.
