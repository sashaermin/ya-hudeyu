## Важные границы аудита

IMPLEMENTED_IN_SOURCE означает подтверждённые действия и хранение/состояния висходниках, не успешный Android runtime test. PARTIAL_DEVICE_VERIFICATION — кодесть, работа датчиков/разрешений не проверена. PARTIAL_SOURCE_AUDIT — маршрут есть, полная внутренняя цепочка не исследована; public text только указывает границу, без инструкции. PLANNED_RELEASE/UNVERIFIED_RELEASE_BEHAVIOR не утверждают существование доступногоAPK или работающегооблака.

Поля модели не автоматически считаются пользовательскими возможностями: например, note есть вBodyMeasurementEntity, но форма замеров не подтверждает отдельный ввод заметки, поэтому ответ его не обещает. Источники state/storage: Today/Stats/Profile/Workout/History ViewModels, Room DAO/entity дляеды/веса/замеров/тренировок/шагов, NutritionWrites/Math/RecipeRepository, preference store. Nutrition/Weight/Measurements используют локальные Compose state+coroutine scope; не выдумывается отсутствующий ViewModel.

Дополнительные маршруты лекарства/цикл/голодание/сон/трекеры/достижения обнаружены вMainActivity/MoreScreen. Не объявляются отсутствующими или сломанными: подробные пользовательские инструкции отложены доотдельного аудита. Медицинские рекомендации/AI/автоанализ/надёжностьsync/media exports не рекламируются.
