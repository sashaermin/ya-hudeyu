# Подготовка Android beta: архитектура и разрешения

Основание: [разрешение Phase3](../project_specs/PHASE3_BETA_AUTHORIZATION_2026-10-20.md). Только development/review, не разрешение публикации. Phase2 и33FAQ сохраняются.

Существующий stdlib static build / GitHub Pages остаётся. `/download` обслуживается `download/index.html` (обычное перенаправление каталога к `/download/`, без JavaScript/router/backend). Один APK хранится как version-specific asset GitHub Releases Android-репозитория; website repository не содержит binaries. Ссылка `/releases/latest/download`, arbitrary Actions artifact и сторонние download hosts запрещены. GitHub asset не криптографически неизменяем сам по себе: включить immutable releases можно только отдельным решением, без изменения инфраструктуры в этой задаче. До него точный tag/asset + byte hash и повторная проверка обязательны; при замене файла ссылку деактивировать.

`data/release.json` — единственный источник версии/URL/байтов/SHA/notes. Дополнения beta: channel,version_code,known_issues,artifact_verification,approval_sha256. `status=verified` с полным artifact_verification означает техническое свидетельство; approved_for_distribution +approval_reference +approval_sha256 — отдельное разрешение владельца точного файла. `data/publication.json.beta_release` — третье независимое разрешение публикации beta website changes с exact artifact_sha256/reference. Старое coming-soon approval эту beta не разрешает. Default beta inactive, неизвестные metadata=null. Неизвестный/ошибочный набор блокирует build вместо выдачи опасной ссылки. Нет динамической загрузки JSON/молчаливого download/аналитики.

Default `/download/` содержит честное unavailable-состояние, оригинальный котик, ссылки на FAQ/политику/проверенный существующий email; никаких APK URL. Available-состояние тестируется только изолированным явно помеченным TEST ONLY fixture. Полный production gate по-прежнему требует verified features и approved screenshots; новый download template не обход gate полного сайта. Draft всегда noindex, production не меняется.
