# Памятка пользователю беты

Пользовательский текст реализован на `/download/` в `templates/download.html` (единственный источник публичной памятки), доступен и при выключенном JavaScript. Это будущие инструкции, а не объявление доступности APK.

- Начать на yahudeyu-app.ru, открыть beta page, проверить версию/дату/размер/минимальный Android/известные ограничения. Скачать только exact GitHub Release APK после его будущего одобрения.
- Сверить SHA256 всей строки: Linux `sha256sum имя-файла.apk`, macOS `shasum -a 256 имя-файла.apk`. Хеш не заменяет доверие к подписи. При mismatch не устанавливать. Не предлагать установку случайных checksum-приложений на Android.
- Открыть файл, при запросе Android разрешить установку только выбранному браузеру/файловому менеджеру. Подтвердить системную установку; можно затем отозвать разрешение источника. Не отключать Play Защиту и остальные меры безопасности.
- Для обновления проверить установленную версию через системные настройки приложения и вернуться на официальный download page. Требуются совместимые applicationId/signing/versionCode. Автообновления и безусловное сохранение данных не обещаются. Не удалять прежнюю установку ради обхода ошибки.
- При ошибке проверить Android, место, размер/хеш, подпись/версию с поддержкой. Сообщить модель/Android/версию/шаги/текст ошибки. Не пересылать личные дневники, медицинские данные, пароли/токены; обезличить снимки.

Feedback: существующий `sashaermin@gmail.com` из original master и data/site.json. Нет нового бота, почты, регистрации, tracker или формы сбора данных. Категории: сбой, расчёты, UI, установка, потеря/повреждение данных, предложения. Возможный будущий публичный issue tracker не включён и не нужен дляготовности текущей страницы; обработка email человеком не проверялась.
